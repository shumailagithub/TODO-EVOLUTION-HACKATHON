# Beautiful Todo App

A stunning, modern Todo application built with React, Next.js, Tailwind CSS, and Framer Motion. Features a premium 2026-inspired design with glassmorphism effects, smooth animations, and dark/light mode.

## Features

- 🎨 **Beautiful UI Design**: Premium glassmorphism cards with subtle blur and shadow effects
- 🌙 **Dark/Light Mode**: Smooth transition toggle with system preference detection
- ✨ **Animations**: Smooth task add/delete/complete animations using Framer Motion
- 📱 **Responsive**: Fully responsive for mobile and desktop
- 🎯 **Task Management**: Create, edit, delete, and mark tasks as complete
- 🔍 **Filters**: All/Active/Completed task filtering
- 📊 **Statistics**: Real-time task statistics dashboard
- ⚡ **Performance**: Optimized with React best practices

## Design Elements

- **Glassmorphism Cards**: With subtle blur and shadow effects
- **Gradient Accents**: Purple to blue and teal to emerald gradients
- **Floating Labels**: Modern input fields with floating labels
- **Particle Background**: Subtle animated particle background for depth
- **Custom Icons**: Beautiful Lucide React icons
- **Typography**: Modern Inter font family
- **Transitions**: Smooth transitions between states

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: JavaScript

## Installation

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to see the beautiful Todo app in action!

## Color Palette

- Primary: Purple to Blue gradient (`from-purple-500 to-blue-500`)
- Secondary: Teal to Emerald gradient (`from-teal-500 to-emerald-500`)
- Background: Gradient backgrounds with subtle animations
- Glass effect: `backdrop-blur-lg border bg-white/10 border-white/20`

## Components

- **Header**: With app title, user welcome message, and logout button
- **Task Creation**: Input section with floating labels and focus glow
- **Task List**: Cards with custom checkboxes and hover actions
- **Stats Dashboard**: Real-time statistics with icons
- **Filter Controls**: Pill buttons for task filtering
- **Empty State**: Beautiful illustration for empty task list
